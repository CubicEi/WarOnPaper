## 游戏介绍

《纸上谈兵 4》是一款极简画风的多人实时战略（RTS）游戏：

- **纸面战场**：暗灰底色、网格地图，建筑落在格点上，部队用简洁的符号表示，一切信息一目了然。
- **通信为王**：命令、产能、视野都依赖从首都扩散出去的通信网。断掉敌人的线缆和电台，往往比正面强攻更致命。
- **双资源经济**：能源 **E** 决定你能建造和训练多少东西，组织点 **O** 决定你能下达多少命令。如何分配这两种资源，是“纸上谈兵”的核心。
- **多兵种协同**：步兵、装甲、海军、航母、空军各有所长，配合臼炮、防空炮、导弹乃至核导弹，构成完整的海陆空作战体系。
- **战争迷雾**：卫星只能看到大型建筑，敌军部队必须靠直接视野才能发现。侦察、伪装与突袭都大有可为。
- **多人对局**：支持 2–10 人自定义房间与快速匹配，也支持 `2v2`、`3v3`、`2v2v2` 等组队模式。

地图有三种尺寸：

| 尺寸 | 格子 | 适用 |
| --- | --- | --- |
| 小型 | 89 × 59 | 匹配 2–3 人 |
| 中型 | 119 × 79 | 匹配 4–5 人 / 组队局 |
| 大型 | 179 × 119 | 自定义房间 |

地图由随机种子生成，包含海洋、陆地、山地、林地、油田与铀矿。

## 基础规则

> 以下是入门所需的核心规则摘要。完整数值请查阅 [《纸上谈兵 4 · 规则文档》](./纸上谈兵4-规则文档.md)。

> 距离单位为 **Du (distance unit) **（1 格边长 = 1 Du）。

### 资源：能源 E 与组织点 O

| 资源 | 用途 | 来源 |
| --- | --- | --- |
| **能源 E** | 建造、升级、修复、训练、装填弹药 | 每秒由建筑产出；首都 +4/秒，炼制资源可大幅提高产量 |
| **组织点 O** | 下达几乎所有命令（建造、进攻、封锁、驻守等） | 每 30 秒由首都与各级指挥所、司令部提供；**上限 50** |

- 每 10 秒，所有在线建筑按体量扣除功耗（小型 1E、中型 2E、大型 4E）。
- **能源透支会伤首都**：结算后若 E 为负，首都扣除等量 HP，E 归零。

### 定都与开局

1. 开局时在地图上选一个格点**定为首都**，获得 `E = 500`、`O = 10`。
2. 首都必须建在内陆平地（不能是海岸、山脚或林地中心），且与其他首都距离 **大于 10 Du**。
3. 首都 HP 120，自带 30U 驻军（驻军不可出城），提供最大的直接视野（R = 10）。

### 通信：一切的前提

**只有接入通信的建筑才能产出能源、提供组织点、提供视野、接受命令**（拆除除外）。

通信从首都出发，沿以下介质扩散：

- **线缆 / 公路**：把通信送到线上的建筑。
- **铁路**：只在**车站**之间传递通信。
- **电台**：把通信跳给工作范围内的其他电台（不直接覆盖普通建筑）。
- **广播站**：接入后，一次性连通全图所有己方电台。

> 切断敌人的通信线，就能让其后方建筑瞬间瘫痪。

### 建筑与升级

- 建筑落在格点上，分为**小型**、**中型**、**大型**三种体量。小型建筑立即完成，中大型需要建造时间。
- 新工地必须位于**直接视野内**，或通过己方公路 / 铁路连到视野内。
- 建造 / 升级消耗 `E =（目标等级 − 当前等级）× 10`，并扣 **2 O**。
- 建筑沿“建造链”升级，主线为：

```
哨站 → 碉堡 → 营地 → 据点 → 指挥所 → 基地 → 市镇 → 都市 → 首府
```

从主线上可分出各类功能建筑：

| 类别 | 代表建筑 |
| --- | --- |
| 指挥与通信 | 电台、雷达、高级指挥所、广播站、区域 / 战区 / 总司令部（提供 O） |
| 兵力 | 兵营、装甲营、港口、机场、训练场、臼炮、防空炮、导弹 |
| 交通 | 车站、线缆、公路、铁路 |
| 能源 | 补给站、伐木场、油井、火力发电厂、铀矿机、铀工厂 |
| 海上 | 人工岛（不可摧毁，可在海上建立据点） |

- 雷达、港口、兵营、装甲营、机场可**线性升级**至 10 级，HP、范围、容量最高提升至 5 倍。
- 拆除建筑可返还部分能源；首府可执行**迁都**（消耗 50 O）。

### 兵种与战斗

| 兵种 | HP | 速度 (Du/s) | 特点 |
| --- | --- | --- | --- |
| 步兵 | 1 | 0.25 | 进入山区减速一半；最灵活，很多建筑都能出步兵 |
| 装甲 | 3 | 0.35 | 无法进入纯山区；需装甲营 |
| 海军 | 2 | 0.5 | 只能在海上行动；需港口 |
| 航母 | 2 | 0.4 | 由港口建造（500E），可搭载 3U 空军 |
| 空军 | 3 | 3 | **不受陆军、海军伤害**；打一轮即返航；需机场 |

- **活动范围**：陆军只能在电台覆盖范围内行动，海军受所属港口范围限制，空军受所属机场范围限制。
- **携行补给**：陆军、海军移动会消耗携行能源，耗尽即停下，可到补给站补充。
- **公路 / 铁路**上行军会大幅提速（公路 0.8、铁路 2 Du/s），陆军也只能借道路跨越海洋。
- **训练**：在训练场下单，按兵种消耗能源（步兵 25E / 装甲 50E / 海军 75E / 空军 125E 每 U），训练完成后自动送往目标建筑。

**主要军事指令**

| 指令 | 说明 |
| --- | --- |
| 调动 | 移动到指定坐标 |
| 封锁 | 在目标点驻扎，自动攻击 R = 2 范围内的敌军 |
| 驻守 | 守在建筑外侧，敌人必须先击破驻守部队 |
| 互防 | 两座相邻建筑互相派兵支援 |
| 进攻 | 攻击敌方单位、建筑或拆除联络线 |
| 停止 / 撤退 | 原地停下，或立刻撤回所属建筑 |

**战斗结算**（每 5 秒一轮）：

- 单位对单位：对方每 1U 对己方造成 1 点伤害，再按 HP 折算剩余 U。
- 攻城顺序：先打**驻守 / 互防援军**，再打**建筑内驻军**，最后才打**建筑本体**。
- 建筑 HP 归零时会被**占领**（可选择修复或拆除）；但如果主要伤害来自空军、火箭军，或建筑正在建造 / 修复，则会被**直接摧毁**。

### 视野

- **卫星视野**（全图默认）：能看到地形、资源位置、大型建筑与铁路、建成后的中型建筑与公路；**看不到敌军部队和小型建筑**。
- **直接视野**：来自己方在线建筑与野外部队，可以看到范围内的一切（敌方部队的具体兵力 U 除外）。

### 经济：开采与炼制

| 开采建筑 | 资源 | 产出 | 炼制建筑 |
| --- | --- | --- | --- |
| 伐木场 | 林地 | 1 / 秒 | 火力发电厂 |
| 油井 | 油田 | 2 / 秒 | 火力发电厂 |
| 铀矿机 | 铀矿 | 3 / 秒 | 铀工厂 |

开采建筑和对应的炼制建筑**都接入通信**后，原料才会转化为能源。资源储量有限，每 30 秒减少 1，枯竭后林地变平地、矿点消失。

### 火箭军与核武器

- 臼炮、防空炮、导弹、远程导弹、核导弹需要装填弹药后才能发射，发射后有冷却。
- 导弹系列需要先进行**研究解锁**，每一阶有成功率，失败则进入下一阶。
- 火箭军**无视守军**直接打击建筑；防空炮可以拦截导弹并对敌方空军造成减员。
- **核导弹**摧毁目标并留下半径 2 Du 的**污染区**：区内建筑全部失效、只能拆除，首都处于污染区会持续掉血。

### 胜利条件

- 首都 HP 归零即出局，所有建筑、部队清空。允许重生的房间可以重新定都，否则转为观战。
- 当场上**只剩一支队伍**拥有存活的首都时，该队伍获胜。
- **组队模式**中，友军之间不可互相攻击，共享通信与视野，首都沦陷后一律转为观战。
