## 2. 初始化

### 2.1 地形生成

地图为 **89×59**（小型）、**119×79**（中型）或 **179×119**（大型）格（经线 90 / 120 / 180，纬线 60 / 80 / 120）。由种子生成海洋、陆地、山脉、石油、铀矿、林地；同一种子、同一尺寸生成的地图相同。默认陆地约占全图 **58%**，山地约占陆地 **12%**，林地约占非山地陆地 **15.4%**。选定山地后还会做一次「水域至少一格宽」的修正，把部分格子改回海洋，所以实际陆地比例略低于 58%。

| 资源 | 面积约束 | 储量规则 |
| --- | --- | --- |
| **石油** | 占全图面积 **< 1%**（格数预算 = ⌊总格数 × 1%⌋ − 1：小 / 中 / 大图 **51 / 93 / 212** 格）；每块 **3–10** 格（被挡住时最少 2 格） | 每块油田储量 = `[15, 25] × 所占格数 + [-30, 20]`；整块矿点共享储量 |
| **铀矿** | 占全图面积 **< 1‰**（预算 = ⌊总格数 × 1‰⌋ − 1：**4 / 8 / 20** 格）；单矿 1 格（55%）或 2 格（45%） | 储量 = `[100, 150] × 所占格数`；整块矿点共享储量 |
| **林地** | — | 按格分别计算，每格储量 = `[12, 20]` |

- 石油与铀矿只避开山地和林地，**可以生成在海上**；油井、铀矿机也可以建在海上的矿格上。
- 方括号 `[a, b]` 表示闭区间内的随机整数。

### 2.2 准备

尚未建都的玩家（含中途加入、重生）可在地图上定都。定都**不要求视野**，也没有时间限制。定都时该玩家的能源与组织点重置为 `O = 10`，`E = 500`。

首都必须落在**内陆陆地格点**：

- 格点周围（最多 4 格，地图外的格子忽略不计）全部是陆地，因此地图边缘、角落的格点也可以定都；
- 不能是山脚（周围任一格是山地）、海岸（周围任一格是海洋）；
- 不能在森林中间（周围格子全是林地）。

与**其他任何存活首都**（敌方、友方都算）的距离必须 **> 10 Du**（等于 10 Du 也不行）。首府、普通建筑不受这个距离限制，只占用自己所在的格点，所以首都可以紧贴敌方普通建筑落下。

**开局准备**（新开局与读档局都有）：

- 定都后进入**准备大厅**，此时模拟尚未开始：没有经济、没有 tick。
- 准备大厅中可以**放弃首都**重新选点。
- 当所有在座玩家都已定都（观战者除外）并都按下「准备」（观战者也要按）后，对局开始。房间只有 1 人时也可以单人开局。
- 中途加入的玩家：定都后立即进入对局，不经过准备。中途加入者没有队伍。

### 2.3 房间与匹配

**自定义房**

- 地图尺寸：89×59 / 119×79 / 179×119。
- 人数上限：**2–10**。观战者也占座位。
- 可选种子（数字或字符串）。
- 重生开关：界面默认开启。
- 房间码为 **6 位**，不含 I、O、0、1；输入房间码时接受 4–8 位。
- 只要有空座，任何拿到房间码的人都能中途加入（匹配房也一样）。

**匹配**

- 自由混战：**2 / 3 / 4 / 5** 人。
- 组队：`2v2` / `3v3` / `4v4` / `2v2v2` / `3v3v3` / `2v2v2v2`，凑满人数后随机分队开局。
- 地图：**2–3 人用小型图**（89×59），**≥ 4 人用中型图**（119×79），从不使用大型图。
- 所有匹配房 `allowRespawn = false`（不可重生）。

**空闲超时**：房间内连续 **5 分钟**没有任何玩家操作（命令、聊天、准备、加入都算操作；心跳和单纯重连不算）时，房间被销毁，进行中的对局也一样。游戏不能暂停。

## 3. 游戏运行

### 3.1 开始与资源 tick

产电、功耗、组织度只统计**已建成、未污染、已接入通信**的建筑。被占领、待处理（HP = 0）的建筑同样算作已建成，照常产电、耗电、加 O。

- 定都：`O = 10`，`E = 500`。组织点上限 **50**。E 没有上限，并且可能出现小数（例如拆除返还）。
- **每秒**：`E += P + 已炼制的 Raw-P`。直产 P 来自已连通建筑（首都为 **P +4**）。Raw-P 须开采建筑与对应炼制建筑都已连通，且开采建筑正压在未枯竭的资源上，才计入。
- **每 30 秒**：已连通建筑的 O 加成求和，增加 O，不超过 50。
- **每 10 秒**：按体量扣减已连通建筑的功耗（见 [开采与炼制](#46-开采与炼制)）。**首都本身也计功耗**（大型，4E）。
- **每 30 秒**：正在开采的资源储量 −1（见 [开采与炼制](#46-开采与炼制)）。
- **每个 tick** 检查一次：若 `E < 0`，首都扣除 **|E|** 点 HP，然后 **E 置为 0**。这次扣血也会打断首都正在进行的修复。

未接入通信、建造中或处于污染区的建筑不产电、不耗电、不加 O。被污染的首都同样不产 P、不加 O、不扣功耗。

上面的「每秒 / 每 10 秒 / 每 30 秒」都按**房间全局时钟**对齐，不是从各自定都时起算。中途定都的玩家，第一次加 O 可能不到 30 秒就来。

### 3.2 执行操作

**通信要求**：以下操作要求该建筑**已接入通信**：

- 升级、线性升级、继续建造、迁都；
- 修复（刚占领、待处理的建筑除外）；
- 装填、部署、发射；
- 训练、建造航母；
- 在人工岛上建造。

以下操作**不检查**建筑是否接入通信：

- 在空地新建；
- 建造联络线（铁路起点车站除外）；
- 拆除；
- 从建筑派兵、改归属、驻守、补给、互防。

**污染**：污染区内的建筑失效，在建筑面板上只能拆除；派兵的来源建筑、互防双方、驻守目标、建造航母的港口被污染时，对应命令也会被拒绝。

同一建筑派出的单位视为一组。市镇、都市、首府、首都的驻军**不能出城**（但可以作为训练目标补员）。兵营、装甲营建成时驻军为 **0**；其余有 U 上限的建筑建成时驻军为满编，原地升级完成时也会**免费补满**驻军（兵营、装甲营除外）。

#### ① 调动

- 选择坐标（步长 **0.2**）并选择若干单位。**−1 O / 组**。
- 寻路在 0.2 网格上按 8 个方向进行，路径长度不限；找不到路径时命令被拒绝（「无法到达目标…」）。
- 陆地、海军可「停止」，停留在当前位置。空军**不能在野外停留**：到达目的地后立即直线返航，入库到所属机场。
- **占位**：只有静止的单位占格；移动中的单位互相穿过，友军不占格。终点被占时，在终点周围 **2 Du** 内找空位（改归属时 3 Du）；找不到就叠放在终点。静止单位不会停在建筑中心格上（海军停在港口格除外）。
- **活动范围**（训练送达、撤退不受此限）：
  - 陆军：己方与友军**已建成**电台工作范围的并集（含雷达协同，见 [通信](#48-通信)）；
  - 海军 / 航母：所属**港口**的工作范围，可在港口格出发或停泊；
  - 空军：所属**机场**的工作范围；
  - 港口、机场只要已建成、未污染，就提供自己的工作圆，不要求接入通信（雷达协同仍要求接入）。
- **起点或终点不在活动范围内，命令直接被拒绝**；路径的每一步也必须在活动范围内。只有行军途中活动范围缩小（例如电台被毁）时，单位才会停在边界。
- 每 U 携行 `carriedE` 正好为 0 时不能出发；出发前不检查携行够不够走完全程，途中耗尽则停在当前位置。
- 从建筑派出的陆军，出现在建筑周围 **12 Du** 内最近的可站立位置。
- **改归属**：把野外单位改挂到另一座同兵种、**已建成**、且有空位的己方建筑，**−1 O / 组**。空军飞向新建筑并入库；陆海军停在建筑外圈，这次移动无视活动范围。正在交战的单位也能改归属（交战随之结束）；航母不能改归属。
- 站在己方**已建成**公路 / 铁路上（距折线 ≤ **0.12 Du**，铁路优先）时，移速改为公路 **0.8 Du/s**、铁路 **2 Du/s**，不再吃山区减速。光缆不加速。速度按即将进入的那一格判定。
  - 友军的公路、铁路**不**提供加速。
  - 敌方（含友军）已建成**公路**只在覆盖了己方某段联络线时才能借道；铁路不能借道。
- 纯海洋上，陆军只有站在上述己方公路 / 铁路上，或站在己方建在海上的非海上建筑（如人工岛改建后的建筑）格点上，才能通过。海军 / 航母只能走纯海洋（港口格除外）。
- 海军可以停在**任意**港口格上，包括敌方港口。
- 回到所属建筑入库后再派出，携行重新补满（只花调动的 1 O）。

**移速参考**（不在公路 / 铁路上时）

| 单位 | 速度 |
| --- | --- |
| 空军 | 3 Du/s |
| 步兵 | 0.25 Du/s（触及山区再 ×0.5） |
| 装甲 | 0.35 Du/s |
| 海军 | 0.5 Du/s |
| 母舰 | 0.4 Du/s |

#### ①′ 训练（训练场补员）

- 在**已接入通信**的**训练场**发起：选择兵种、数量 U、一个或多个目标建筑；扣 **2O** 与 E 后进入训练场计时队列（FIFO）。多目标时按勾选顺序用各建筑空位分配 U，每个目标各生成一条队列条目；合计空位不足则拒绝。
- **费用**：**2O / 次**（每次下单，不按 U）；另按 U 扣 E：步兵 **25E**，装甲 **50E**，海军 **75E**，空军 **125E**。
- **用时** = 本条目消耗 E / **20** 秒，四舍五入到 0.2 秒。
- 一座训练场的队列里**不能混合兵种**。下单后**不能取消**，没有退款。
- 训练场被污染时队列暂停；未接入通信时队列照常推进（但不能下新单）。训练场被拆除或被占领时，队列全部作废，不退费。
- 完成后自动调动到目标建筑，单位的所属建筑即为目标建筑。训练送达**无视电台 / 机场 / 港口活动范围**，途中不扣携行，写入该建筑驻军（受目标 U 上限约束）。若目标建筑已不存在或无路可达，这组单位停在训练场旁（海军也一样）。
- **训练产出默认满携行**：陆海军 `carriedE` = 该种类携行上限（空军无携行，为 0）。从建筑派出时同样默认满携行。
- 目标兵种须与建筑匹配：装甲 → 装甲营，海军 → 港口，空军 → 机场，步兵 → 可出步兵的建筑（含市镇、都市、首府、首都、补给站，以及表中标「可出步兵」的建筑）。

#### ①″ 停止与撤退

| | 停止 | 撤退 |
| --- | --- | --- |
| 对象 | **驻守、封锁、移动中**：陆海军停在原地；空军改为返航入库。结束驻守 / 封锁。**攻城且仅拆城防**（建筑内驻军已清空、未与城外驻守/互防守军交战）时，陆海军可停止：再打 **1 个攻城节拍**后变为**停留** | 任意兵种，立刻规划回家；母舰返回所属港口旁并进入**停港**，不进入港口驻军 |
| 限制 | 打守军、野战交战、停留、停泊、停港、训练途中、已经在撤退中不可停止；空军不能在野外停留，攻城时也不能用停止 | 所属建筑已不存在或已被占领时不可撤退；撤退途中不再接受其他命令 |
| 寻路 | — | 无视活动范围。海军、空军也无视地形（必要时走直线）；**步兵、装甲仍受地形限制**，无路可回则拒绝 |
| 费用 | **移动中停止** **−20 E、−3 O / 次**（按命令计，与组数无关）；**攻城 HP 阶段停止** **−2 O / 组**（调动费用的 2 倍，无 E）；结束驻守 / 封锁不扣 | 不扣 E / O |

#### ② 封锁

- 选择坐标（步长 0.2）并选择若干单位。单位先移动至目标坐标，然后与进入 **R = 2** 范围内的敌军交战。
- **进入**：下令时立即 **−5 O / 次**，并 **−2 E / 每 1U**。
- **维持**：到达后每 **5 秒**再 **−2 E / 每 1U**。能源不够则退出封锁、变回停留，且这一拍不攻击。每组封锁单位各自计时，第一次维持扣费和第一次交战都在**到达后 5 秒**。
- 每一拍对 2 Du 直线距离内的每个非友方单位组各结算 **一轮**单位战（见 [单位 vs 单位](#42-单位-vs-单位)），包括移动中、撤退中、训练送达中的单位和空军。被打的单位不会被拦停，会继续移动。
- 陆海军封锁对空军造成的伤害为 0，但空军照常还击。
- 两支敌对封锁部队相距 2 Du 以内时，双方都会结算，等于每 5 秒交战两轮。
- 友军单位可穿过己方封锁，不受伤害。
- 维持扣费最多把 E 扣到 0，不会因此扣首都 HP。

#### ③ 互防

- 两座**己方、已建成、边或角相邻**的建筑可以互防，消耗 **−2 O**。双方都要有能出城的驻军（至少 1U），且都还没有互防对象、也没有被驻守。市镇及以上聚落与首都不能互防；不能与友军建筑互防。不检查通信，只检查污染。
- 形成互防后，一方第一次被攻城时，另一方派出**全部**驻军赶去保护（只派一次）。这些援军一出发就算作外部守军，不论距离。进攻方必须先击破这些援军，才能打建筑内驻军，再才能打建筑本体。
- 援军沿电台活动范围寻路，无路可走则不来援。
- 进攻方全部离开或被消灭后，援军回家，**这对互防随即解除**。因此一次互防只生效一次。
- 已进入互防的建筑：**不可**再与其他建筑互防，也**不可**再被驻守。
- 任一方可解除互防，不退 O。伙伴被拆、被毁、被占领或离图时，互防自动解除。

#### ④ 驻守

- 选择一栋建筑与若干单位；单位移动到该建筑**外侧**空位（2 Du 内）后进入驻守。不能驻守友军建筑。
- 进攻方须先击破驻守单位，才能攻击建筑内驻军，再才能攻击建筑本身。多组驻守单位可以守同一座建筑，它们轮流以全部兵力与**每一个**进攻组交战。
- **可对建造中的建筑进行驻守。**互防中的建筑不能再被驻守。
- **进入**：下令时立即 **−5 O / 次**，并 **−1 E / 每 1U**。
- **维持**：此后每 **5 秒**再 **−1 E / 每 1U**。能源不够则离开驻守。维持扣费最多把 E 扣到 0。
- 结束驻守不扣费。

#### ⑤ 建造

**建造建筑**

- 选择格点。点在非格点上时，吸附到最近的节点。一个格点只能有一座建筑；没有最小间距，可以建在敌方联络线上、单位所在格上，也可以建在山地 / 山脚上。
- **视野与施工**：下单时**不检查视野**，任何格点都能下单并扣费。但施工只在工地处于己方**直接视野**内，或落在己方已建成的公路 / 铁路上且该路网能连到某个处于直接视野内的节点时才推进；否则每个 tick 都暂停。本应立即完成的小型建筑若在视野外下单，会变成 HP 0、等待视野的工地。友军的视野与路网**不**算。
- 消耗 E =（目标累计等级 − 当前累计等级）× **10**，并 **−2 O**。从空地建造时，当前累计等级为 0。
- 从空地可以直接建造链上任意建筑（例如直接建据点，花 100E），不必逐级升级。
- 资源建筑必须压在对应资源上（格点周围 4 格任一格即可）：伐木场 → 林地，油井 → 油田，铀矿机 → 铀矿。港口必须在海岸（邻海，且邻陆或邻山）。人工岛只能建在海上（格点周围全是海洋）。普通建筑不能建在纯海上，人工岛除外。
- 总司令部在建造树中标注「每名玩家限一座」，但当前版本**并不强制**（见 [附录](#9-附录--已知实现问题)）。
- 污染区内禁止新建；工地被污染时暂停施工（不会被摧毁）。
- 耗时：
  - **小型建筑**（从空地）：立即完成，不论累计费用多高；
  - **中型 / 大型建筑**：`E / 10` 秒（E 为本次建造消耗的能源），四舍五入到 0.2 秒。
- 建造中 HP = HP 上限 × 已经用时 / 总用时（刚下单时 HP 为 0）。
- **受击**：施工立即**中止**（不再自动推进），并正常扣血；HP 归零则**摧毁**（不可占领）。
- **继续建造**：未摧毁且已接入通信时可下。费用同修复缺失 HP，不扣 O，用时为修复公式 **×2**。完成后**整座建筑直接建成**（满 HP），剩余的建造时间不再需要。继续建造的推进不检查视野。

| 视野类型 | 小型 | 中型 | 大型 |
| --- | --- | --- | --- |
| 卫星视野 | × | 建成后可见 | √（建造中也显示为已建成的样子） |
| 直接视野 | √ | √ | √ |

**建造联络线**

- 选择一条由相邻格点（边或对角线）组成的折线。基础消耗：

```
E = ⌊长度⌋ × 造价系数 × 10
```

长度不足 1 Du 时，这段基础造价为 0。公路、铁路另加地形附加费（见 [交通建筑](#74-交通建筑)），附加费按实际穿越长度计算。

- 计费细节：与己方同级或更高级旧线重合的段、笔画自身重复的段不计费；⌊长度⌋ 作用于去重后的**总**计费长度；地形附加费按各碎段分别取整后求和；投入 E 按长度比例分到各碎段（取整），每个碎段按自己的费用单独计时。
- 耗时：`E / 10` 秒，四舍五入到 0.2 秒；不足 1 秒立即完成。建造联络线**不扣 O**。
- 单条长度必须 **<** 上限：线缆 10 Du，公路 20 Du，铁路 30 Du。长度按整条笔画计算，包括不计费的重合段。
- 联络线**不检查视野、通信和污染**，施工也不会因此暂停。线缆、公路的端点不必落在建筑上。
- 铁路只能从**自己的、已建成且已接入通信**的车站画起，终点必须是**自己的**车站（建造中的车站可以作为终点）。起终点须是两座不同的车站；中间节点不限。
- 与己方已有联络线重叠时，较高一级替换较低一级（铁路 > 公路 > 线缆），被盖住的部分按已投入 E 的 **80%**（向下取整）返还。
- 可与**敌方/他方**联络线重叠：同一格边可并存多条不同归属的联络线；绘制时优先显示己方（及友军蓝色）。单位可**借道**覆盖了己方联络线的敌方已建成公路（移速与过水同公路）。
- 建造中或升级中的联络线不能被选为进攻目标。建造中的联络线不传递通信。

| 视野类型 | 线缆 | 公路 | 铁路 |
| --- | --- | --- | --- |
| 卫星视野 | × | 建成后可见 | √（只显示「建造中 / 已建成」，看不到进度） |
| 直接视野 | √ | √ | √（同样看不到敌方进度） |

#### ⑥ 升级

- 选择已接入通信的己方建筑，升到建造链上的**任意后代**（例如哨站可直接升市镇），不必逐级。
- 消耗 E =（目标累计等级 − 当前建筑类型的累计等级）× **10**，并 **−2 O**。按建筑表中的累计等级计算，与这座建筑实际投入过多少 E 无关（被占领、迁都或做过线性升级的建筑也照此计算）。
- 耗时 = 本次消耗 E 的 **1/10** 秒；不足 1 秒则立即完成。注意：原地升级到小型建筑**也要计时**（例如哨站 → 据点 80E、8 秒），只有从空地建小型建筑才立即完成。
- 升级目标为**小型或中型**时，升级过程对敌方卫星不可见，卫星仍显示升级前的外观；大型升级对卫星可见。
- **HP 未满的建筑须先修复再升级。**
- 升级开始时 HP 变为 **0**，然后 HP = HP 上限 × 已经用时 / 总用时。受击、视野要求、继续建造的规则同建造。升级刚开始的建筑一击即毁。
- 升级开始时：驻军 U、补给站储能、弹药**清零**（不退），线性等级重置为 1。升级完成时，除兵营 / 装甲营外免费补满驻军。
- 升级中的建筑不提供直接视野。

##### ⑥′ 线性等级升级（雷达 / 港口 / 兵营 / 装甲营 / 机场）

- 建成后为 **1 级**，最高 **10 级**。己方可见：建筑图标左下角以罗马数字 **I–X** 显示（白字、无描边）；友军、敌方看不到等级。
- 从等级 **L** 升到 **L+1** 消耗 **(L+1)⁵ E**（升到 2 花 32E，升到 3 花 243E，升到 10 花 100000E；1 → 10 合计 **220824E**）；立即完成，不扣 O。花费计入建筑投入 E，影响拆除返还。
- 要求：已接入通信、未污染、已建成、不在修复中、**HP 已满**。
- **HP / R / Umax**（有则升）：`值(L) = 基值 × (1 + 4×(L−1)/9)`，即 1 级 = 基值、10 级 = 5×基值，中间线性。HP 与 Umax 四舍五入取整，R 不取整。升最大 HP 时，当前 HP 同步加上差额；升 Umax **不会**增加当前驻军。

| 建筑 | HP（1 / 5 / 10 级） | Umax（1 / 5 / 10 级） | 工作 R（1 / 5 / 10 级） |
| --- | --- | --- | --- |
| 雷达 | 5 / 14 / 25 | — | 8 / 22.2 / 40 |
| 港口 | 12 / 33 / 60 | 4 / 11 / 20 | 8 / 22.2 / 40 |
| 兵营 | 12 / 33 / 60 | 8 / 22 / 40 | — |
| 装甲营 | 25 / 69 / 125 | 12 / 33 / 60 | — |
| 机场 | 40 / 111 / 200 | 8 / 22 / 40 | 10 / 27.8 / 50 |

#### ⑦ 拆除

- **−1 O**（拆建筑）。**首都不可拆除。**拆除不检查通信与污染，修复中也可以拆。
- 修复完成、修复立即完成、继续建造完成后 **60 秒内不可拆除**。
- 拆除时，驻军、补给站储能、弹药、训练队列一律丢失，不退。
- 返还 E（不取整，可能出现小数）：

| 状态 | 返还 |
| --- | --- |
| 已下单、建造计时尚未开始（一个 tick 都没推进） | 已投入 E 的 **100%** |
| 建造进行中 | 已投入 E 的 **90%**（不按当前 HP 折算） |
| 已建成 | `(剩余 HP / 最大 HP) × 已投入 E × 80%` |
| 占领后、待处理（HP = 0） | 已投入 E 的 **50%** |

- 升级进行中被拆时，「已投入 E」按**目标建筑**的累计投入计算。
- 联络线拆除（整条或重叠替换）返还已投入 E 的 **80%**（向下取整），施工中的线也是 80%。拆联络线**不扣 O**，也不要求接入通信。

#### ⑧ 进攻

- 选择若干己方单位与敌方单位、建筑或联络线段为目标。不能以友军为目标。含空军或海军（含航母）时 **−3 O / 次**，否则 **−2 O / 次**。
- 陆军、海军先调动到目标，再进入持续交战，每 **5 秒**一轮。目标位置在下令时**固定**，不会追击；到达后无论与目标相距多远都开始交战，目标被**钉住**（停止移动、路径清空）。陆海军钉不住空军，也钉不住正在返航的空军。
- **空军是打了就走**：到达后只打一轮，然后直线返航，入库到所属机场（返航无视活动范围）。打建筑时，若有驻军先打一轮驻军（驻军对空军的伤害为 0），**并且**再对建筑打一轮 HP，建筑对空军造成 ⌈U / 3⌉ 减员。这一轮若把建筑打到 0，建筑**直接摧毁**。
- 攻城的每一拍按下面的顺序，**只做其中一件**：
  1. 建筑外有驻守单位或互防援军：只与他们交战；
  2. 否则若建筑内还有驻军：只与驻军交战（驻军依次与每个进攻组交战，每次都以剩余全部兵力出手）；
  3. 否则：参战单位对建筑造成 **⌊U⌋** 点伤害，建筑对参战单位造成 **⌈U / 3⌉** 点减员（按各方 U 分摊）。
- **占领与摧毁**见 [单位 vs 建筑](#43-单位-vs-建筑)。
- **拆联络线**：一次只拆一段（正交 1 Du，对角 √2 Du）。先移动到该段附近（约 2.25 Du 内），再用时等于建造这一段的秒数（含公路 / 铁路的地形附加费）。时间到后该段断开，折线拆成剩余的碎段。
  - 同一段上的所有拆线单位共用一个计时，多派单位不会更快；拆线中的单位算作「交战中」，不能调动或停止。
  - 空军对联络线下令会扣 3 O，但到达后直接返航，**拆不断**联络线。

#### ⑨ 修复

- 选择建筑，补满缺失 HP。**不扣 O**。要求：已接入通信（刚占领、待处理的建筑除外）、未污染、已建成或处于需要「继续建造」的状态、不在修复中、HP 未满。
- **费用**：标准 **6E / HP**；**修复首都**为标准的 **5 倍**（30E / HP）。缺失 HP 可以是小数，按实际缺失计费。
- 耗时 = 消耗 E / **10**（首都 E / **25**），四舍五入到 0.2 秒；不足 1 秒则立即完成。即普通建筑每 HP 0.6 秒（缺 1 HP 立即完成），首都每 HP 1.2 秒，继续建造每 HP 1.2 秒。
- 修复中 HP = 修复前 HP + 预计修复 HP × 已经用时 / 总用时。
- 修复中受击：修复**被取消**，进度清零，已花的 E **不退**，需重新下修复。首都因 E 为负或污染被扣血时同样会取消首都修复。
- 修复中被打到 HP 0 则**摧毁**，不可占领。
- 修复不补驻军：被占领的建筑修好后驻军仍为 0。

#### ⑩ 发射

臼炮、防空炮、导弹、远程导弹、核导弹在工作范围内发射，每次消耗 **1 发**弹药。发射要求发射建筑已建成、已接入通信、未污染。发射后进入冷却，冷却秒数 = **装填单发 E / 30**，向上取整到 0.2 秒：臼炮 **2.8** 秒，防空炮 **3.4** 秒，导弹 **6.8** 秒，远程导弹 **20** 秒，核导弹 **166.8** 秒。

- **臼炮打单位**：仅臼炮可以，任何兵种（含空军、航母）都能打。伤害按对单位 H = **2**，用与单位战相同的公式减少目标 U：`⌊(U × HP − 2) / HP⌋`。
- **打建筑**：造成该建筑的 H。**所有发射**（臼炮与火箭军）都**无视守军**，直接打建筑 HP；HP 归零时**直接摧毁**，不可占领。臼炮的炮弹不能被防空炮拦截。
- 可以打建造中的建筑；不能打已经 HP 0（待处理）的建筑，也不能打人工岛。
- 发射不要求能看到目标，只要目标在工作范围内。
- **核导弹**：命中造成无限伤害并摧毁目标，同时在命中点生成污染区。装填条件见 [兵力建筑](#73-兵力建筑)。
- 防空炮可在工作范围（含雷达协同）内拦截飞行中的火箭军弹道，见下方防空结算。被拦截则不造成伤害、也不产生污染，但发射方照样消耗弹药并进入冷却。

**装填**：**−1 O / 次**（与发数无关）。实际装填发数 = min(请求发数, 剩余弹药空位, ⌊E / 单发费用⌋)，能源不够时只装能装的部分。装填要求已接入通信、未污染，不受发射冷却影响，也不要求满 HP。

#### ⑪ 迁都

- 在**已建成、HP 已满、不在修复中、已接入通信、未污染**的首府上迁都，消耗 **−50 O**。首都本身须不在修复中（不要求首都满血）。
- 首府所在格变为首都：HP 上限改为 120，当前 HP 保持首府被迁之前的 HP（因此新首都通常不满血）。原首都所在格变为首府：HP 上限改为 100，当前 HP = min(100, 原首都 HP)。
- 两侧驻军保留原数，按新建筑的 U 上限截断（新首都不会自动补到 30）。原首都变成的首府，投入 E 至少记为 1000。
- 格点与建筑实例保持不动，联络与单位归属继续有效。

### 3.3 计时与结算顺序

**计时粒度**

- 1 tick = 0.2 秒。建造、升级、修复、继续建造、训练、研究、联络线的用时都换算成 tick（四舍五入，至少 1 tick）；发射冷却向上取整。
- 「不足 1 秒立即完成」适用于升级、修复、继续建造与联络线；训练不足 0.2 秒才立即完成。
- 交战（5 秒一轮）、封锁、驻守维持按各单位自己的计时累计；经济、污染扣血、核研究设施检查按房间全局时钟对齐。

**每个 tick 的处理顺序**

1. 同步污染标记；
2. 推进建造（含联络线）；
3. 推进修复与继续建造；
4. 研究结算；
5. 污染扣首都 HP（每 3 秒）；
6. 通信扩散（见 [通信](#48-通信)）；
7. 经济：每 30 秒先扣储量 → 每秒刷新储量揭示 → 各玩家依次：每秒收入 → 每 10 秒功耗 → 每 30 秒加 O → 检查 E < 0 并扣首都 HP；
8. 训练、单位移动、防空；
9. 封锁、驻守维持扣费；
10. 交战与攻城；
11. 拆联络线；
12. 检查首都存亡与胜负。

由此可知：同一秒的收入先于功耗入账；资源在某个 30 秒点枯竭时，这一秒已经没有这份收入；封锁 / 驻守扣费不会触发首都扣血。

## 4. 计算

### 4.1 战斗 · 各单位性质

> 单位战里，对方的 **1U** 对己方造成 **1** 点伤害项（再按 HP 折成剩余 U）。空军不受陆军、海军的这项伤害。

| 单位 | HP | 速度 | 携行上限 | 1E 可行 | 特殊 |
| --- | --- | --- | --- | --- | --- |
| 步兵 | 1 | 0.25 Du/s | 5E | 15 Du | 触及山区（含山脚）速度 ×0.5 |
| 装甲 | 3 | 0.35 Du/s | 5E | 5 Du | 禁止进入纯山区（山脚、临海山崖、己方公路 / 铁路上可过） |
| 海军 | 2 | 0.5 Du/s | 10E | 2 Du | 只能走纯海洋 |
| 母舰 | 10* | 0.4 Du/s | 10E | 2 Du | 1U 船体；港口建造费 2000E；机库容量 5U 空军 |
| 空军 | 3 | 3 Du/s | — | — | **无视陆军、海军伤害**；不耗携行；不能在野外停留 |

`*` 母舰是单艘舰体的当前耐久，受伤时逐点累积扣减，不套用普通单位战的 U 向下取整公式；舰体 HP 降至 0 才损失这 1U 母舰。

### 4.2 单位 vs 单位

持续交战、封锁中的交战，都是每 **5 秒**结算一轮。一轮内双方同时结算。

- 默认「对 A 的伤害项」= `UB0`，「对 B 的伤害项」= `UA0`（空军 vs 非空军时，对空军的伤害项为 0）。野外单位组将伤害项视为 **点数**：每 1 点随机选一个 U 槽位 −1 HP，槽位 HP 归零则损失 1 U。
- **建筑驻军**无槽位 HP，仍按聚合公式一次结算：`⌊(U×HP−伤害)/HP⌋`。
- 航母例外：对其造成的伤害直接从当前舰体 HP 扣除；当 HP 降至 0 时才损失航母 U。
- **空军不受陆军、海军伤害**：被打的一方是空军、打它的一方不是空军时，对该空军的伤害项为 **0**。机场驻军按空军计，所以陆海军打不掉机场里的空军驻军，而这些驻军照常还击。
- 若 `UA1 ≤ 0` 或 `UB1 ≤ 0`，该方单位消失，战斗结束；否则以新的 U 进入下一轮。
- 多组同时交战时，按组逐对结算（顺序由内部编号决定，可视为随机）。

### 4.3 单位 vs 建筑

持续攻城每 **5 秒**一拍。有外部守军时这一拍只打守军；没有外部守军但有建筑内驻军时只打驻军；两者都没有时：

- 单位对建筑造成 **⌊U⌋** 点伤害（U 为这一拍仍在打的单位数之和）；
- 建筑对单位造成 **⌈U / 3⌉** 点伤害，按各方 U 分摊：每组分到 ⌊总量 × 本组 U / 总 U⌋，余数由最后一组承担。每 1 点伤害随机选一个 U 槽位 −1 HP，槽位 HP 归零时失去该 U（与野战相同）。

空军抵达时的那一次空袭例外：先打驻军（若有），然后**同一轮**再打建筑 HP，随后返航。

**占领与摧毁**

- 地面攻城（陆军 / 海军）的一拍把建筑打到 HP 0，且当时**不是**建造中（含升级中）、**不是**修复中：建筑被**占领**。所有权交给进攻方（多名玩家同时攻城时交给编号最小的一方），HP 记为 0，驻军清空，训练队列作废，互防解除，进入待处理。储能、弹药、投入 E、线性等级保留。占领方可选择：
  - **拆除**：返还已投入 E 的 **50%**；
  - **修复**：按剩余 HP = 0 来修。
- 待处理（HP = 0）的建筑只需再挨一拍地面攻城就会被重新占领。
- 建筑当时正在建造 / 修复：HP 归零时**直接摧毁**，不可占领。
- **空军**空袭打出的最后一击：直接摧毁。空军不会留在攻城中，所以「空军伤害占比」实际只由这一击决定。
- **发射**命中（臼炮或火箭军）：无视守军，直接对建筑造成 H；HP 归零时**直接摧毁**。

### 4.4 补给

- 长距离移动消耗携行。按单位组的**每 U 携行填充量** `carriedE` 结算：

| 单位 | 1E 可移动 | 每 U 携行上限 |
| --- | --- | --- |
| 步兵 | 15 Du | 5E |
| 装甲 | 5 Du | 5E |
| 海军 / 航母 | 2 Du | 10E |
| 空军 | 不消耗 | 无 |

- 移动距离 `D` 时，每 U 扣 `D / duPerE`。携行用尽则停在当前位置。
- 单位移动到己方补给站（邻格也算到达）可补给，**−1 O / 次**（下令时即扣，到达后补给失败也不退）。
- 每 U 补充量 = min(⌊每 U 缺口⌋, ⌊站内 storeE / U⌋)，按整 E 计，可以只补一部分。**每 U 至少恢复 1E**，站内储能不够这一下限则这次补给失败。每 U 缺口不足 1E 时命令被拒绝（「携行补给已满」）。
- 不能使用友军补给站。空军不能执行补给命令。入库、训练送达、撤退途中不扣携行。
- **单位 HP 修复**：野外单位每组内部按 **U 槽位**分别记录 HP（满血 = 目录 `HP/U`）。到达己方补给站（邻格也算）完成携行补给后，若仍有受损槽位，则按 **受损最重的一个 U** 开始，**每秒恢复 1 HP**，同一时间只修一个槽位（与母舰停港每 2 秒 1 舰体 HP 类似，补给站为每 1 秒 1 HP）。离开补给站范围或满血后停止。信息框编制条显示 **当前 HP 总和 / 出发时 U×HP/U**（`出发时 U` 为该组首次离城时的编制数）。

### 4.5 视野

视野分为 **直接视野** 与 **卫星视野**。

直接视野只由下列来源提供：

- 己方与**同队友军**、**已接入通信**、**未污染**的建筑（首都，或已建成；建造中、升级中的建筑不提供视野）。友军建筑须在本队共享的通信网内才算。
- 己方 / 友军在野外的单位，不论是否有通信（含训练送达中、驻守中、封锁中的单位）。

通信扩散同样把同队建筑与联络线视作己方网络。

**判定方式**：直线距离 ≤ R 即可见（含边界）。建筑、联络线按格点计，单位按其 0.2 步长坐标计，资源储量环按格子中心计。联络线只要有一个节点在视野圆内就算在直接视野中。视野每个 tick 重新计算一次。

**没有战争迷雾记忆**：敌方建筑离开直接视野后立即退回卫星视野的显示（小型建筑、未建成的中型建筑、线缆直接消失）；敌方单位离开视野即消失，没有「最后所见」。

#### 4.5.1 卫星视野

- 默认全图具备卫星视野。
- 可见：地形、矿点位置、污染区、资源枯竭，以及下表中的建筑与联络线。卫星下建筑的血量、驻军、储能、弹药、建造投入都不可见；中小型建筑升级时仍显示升级前的外观；大型建筑建造中看起来与已建成相同。
- **不可见：敌军单位。**储量环也不在卫星下出现。

| 对象 | 卫星 |
| --- | --- |
| 小型建筑、线缆 | 不可见 |
| 中型建筑、公路 | 建成后可见；公路的建造进度不可见 |
| 大型建筑、铁路 | 可见；铁路只显示「建造中 / 已建成」，看不到进度 |

#### 4.5.2 直接视野

| 来源 | R |
| --- | --- |
| 雷达 | 4（不用小型建筑的 3；线性升级不提高） |
| 小型建筑 | 3 |
| 中型建筑 | 5 |
| 大型建筑（含港口、机场、核导弹、人工岛） | 8 |
| 步兵单位 | 2 |
| 装甲 / 海军 / 航母 | 4 |
| 空军单位 | 8（**只**能看到其他空军；看不到建筑和陆海军） |
| 首都 | 10 |

- 直接视野中，敌方建筑的类型（升级中显示升级目标）、HP、建造剩余可见；驻军、储能、弹药、投入 E、等级、通信状态、冷却、污染标记不可见。
- 敌方单位的位置、兵种、状态（静止、移动、训练送达、驻守、封锁、交战、停港）可见；**编制数 U、携行、路径、机库载机不可见**。
- 资源储量环只在直接视野里出现（空军视野不算），而且要等该资源被开采过。
- 观战者（含出局后转观战的玩家）拥有**全图完整视野**。

新建工地的施工条件见 [建造](#⑤-建造)：在直接视野内，或经己方已建成公路 / 铁路连到直接视野。

### 4.6 开采与炼制

- 开采建筑脚下有对应资源、且与对应炼制建筑都已接入通信时，**每秒**把 Raw-P 炼成 E：
  - 伐木场 Raw-P **1**、油井 Raw-P **2** → **火力发电厂**；
  - 铀矿机 Raw-P **3** → **铀工厂**。
- 一座炼制建筑就能炼制所有对应开采建筑的产出，没有数量上限。同一油田 / 铀矿上放多台开采建筑，收入叠加。
- 开采建筑压在周围 4 格中任意一格资源上就算数。伐木场依次采完它接触的林地格，顺序为左上 → 左下 → 右上 → 右下（以格点为中心）。
- 开采建筑**已建成、未污染**，资源就**每 30 秒储量 −1**（**不要求**接入通信或有炼制厂）。同一油田 / 铀矿即使有多台开采建筑（含敌我双方），这一拍也只扣 **1**。林地按开采建筑实际打到的那一格扣。储量为 0 时枯竭：林地变回普通陆地，油田 / 铀矿整块消失。
- 建筑功耗（每 10 秒，仅已建成、未污染、已接入通信；首都、人工岛也计）：

| 体量 | 功耗 |
| --- | --- |
| 小型 | 1E |
| 中型 | 2E |
| 大型 | 4E |

- 资源点储量仅在**首次开采之后**、且位于直接视野内时，对玩家可见。「开采过」是**全局共享**的：任何玩家的已建成、未污染开采建筑压上去（不要求通信）就会揭示，之后所有玩家（含敌方）在直接视野内都能看到储量，开采建筑拆掉后也保持揭示。

### 4.7 地形

格点（建筑所在点）的地形由周围最多 4 格决定；单位坐标的地形按实际几何判定：落在格子内部只接触这一格，落在网格线上接触 2 格，落在格点上接触 4 格。

**山区**

- 触及山区（接触任一山地格，含山脚）的步兵速度 **×0.5**。已经走在己方公路 / 铁路上时，用公路 / 铁路速度，不再乘这个系数。
- 装甲**禁止进入纯山区**：只接触山地、不接触陆地也不接触海洋的位置。同时挨着山地和陆地的山脚、挨着海洋的山崖、己方（或借道）公路 / 铁路上都可以过。因此装甲只能沿着与陆地或海洋接壤的网格线、格点穿越山区。
- 「山脚」一词在不同规则中含义不同：定都时，周围任一格是山地就算山脚（不可定都）；公路 / 铁路附加费与装甲通行中，山脚指同时接触山地与陆地、且不接触海洋。

**海洋**

- 海军、航母只能处于纯海洋（港口格允许出发和停泊）。
- 陆军遇到纯海洋时，只有站在己方已建成的公路或铁路上才能通过。
- 空军忽略地形。

### 4.8 通信

命令、产电、功耗、组织度、直接视野，都依赖从首都扩散出去的通信。首都被污染时，通信不再从这座首都向外扩散（被污染的首都本身仍算接入）。组队模式下，通信从**全队所有首都**同时出发，所以首都被污染的玩家仍可能经由友军网络接入。

通信沿这些介质走，走到建筑上才算接入：

- **线缆、公路**：沿折线把通信送到线上的建筑。
- **铁路**：只把通信送到**车站**，再由车站继续传。铁路沿线的其他建筑不会因为铁路本身而接入。
- **电台**：只把通信跳给自己工作范围内（≤ R，含边界）的其他电台（工作范围可并入近处雷达，见下）。电台不直接把通信辐射给范围内的普通建筑。
- **广播站**：须已建成、未污染，且通信须经线缆或公路（不能经铁路）送达。一旦接入，连接全图所有已建成、未污染的电台（含友军电台，不限距离），再从那些电台继续扩散。

**信号预算**：信号从 1 出发；在最大长度为 M 的介质上走 d Du 消耗 d / M（线缆 M = 10，公路 20，铁路 30，电台跳转用其工作 R）。换介质时按剩余比例继续。到达任何一座接入的建筑时预算重置为 1，剩余正好为 0 时也算到达。实际效果：沿线相邻两座建筑之间的距离不能超过该介质单条长度上限。

**传递规则**

- 已建成的己方与友军联络线、建筑、电台都传递通信；**敌方**联络线从不传递。建造中的联络线不传递。
- 建造中、升级中的建筑也会被接入并重置预算；被污染的建筑不接入、不重置预算，但信号可以从它所在的线上穿过。被污染的联络线照常传递。

**扩散速度**：每秒（5 tick）开始一轮新的扩散（上一轮结束后），每 tick 推进 48 步，一轮结束后才更新「已接入」名单。新建筑、刚完工的线、被切断的线一般在 **1–2 秒**后生效，大网络更久。一轮开始后才加入的建筑和线要等下一轮。

**雷达协同**：一座已接入通信、本身有工作半径的建筑，若与**己方**已接入通信的雷达距离 **< 1.5 Du**（即相邻的 8 个格点），则把该雷达的工作圆并进自己的工作范围。单位活动范围、防空、发射、电台跳转都用这个并集。友军雷达不参与协同。电台跳转使用上一轮的接入名单，所以新接入的雷达要晚一轮才扩大跳转范围。

雷达的**工作半径**（1 级为 8，可线性升级）和**直接视野半径**（固定 4）不是同一个数。

单位活动范围见 [调动](#①-调动)。友军电台同样扩大己方陆军的活动范围。训练送达和撤退不受活动范围限制。

## 5. 胜利条件

首都 HP 归零或被移除时，该玩家出局：

- 其拥有的所有建筑（含占领来的）、联络线（含施工中的）、单位、通信网全部清空，不退任何资源；发出的友方进驻申请一并作废。
- 别人从他手里占领的建筑仍归占领方。友军存放在他建筑里的兵随建筑消失；他存放在友军建筑里的兵留给友军。
- 房间若允许重生，该玩家可以重新定都（没有冷却和额外条件）：E 重置为 500、O 为 10，已解锁的研究保留，进行中的研究取消。否则转为观战：首都 HP 显示为 0，E / O 冻结。

**胜负判定**

- 胜负只在有首都陷落时检查。当场上曾经同时存在至少两座首都（友军首都也算），之后只剩**一支队伍**（或独行玩家）还有存活首都时，该队伍全部成员胜利。自由混战中每人独自一队，效果等同「最后一名有都玩家胜」。从未定都的玩家不影响判定。
- 一旦只剩一支队伍有首都，对局**立即结束**，即使落败方本可以重生。因此 2 人房即使开启重生，第一座首都陷落就分出胜负。
- 获胜者为获胜队伍的所有在座成员，包括已出局的队友和掉线的座位；已离开房间的玩家不计。
- 若所有首都同时陷落，没有胜者，房间在空闲 5 分钟后关闭。
- 宣布胜利后房间**立即关闭**，不保留赛后状态。

能源供应不足不是单独的胜利状态：结算后 E 为负时，按差额扣首都 HP 并把 E 清零。扣到 0 则首都陷落，按上面的出局处理。核污染中的首都每 **3 秒**再扣 **1** HP，同样可以导致陷落。

### 5.1 组队模式

- **匹配**：见 [房间与匹配](#23-房间与匹配)。组队匹配凑满人数后随机分队。
- **自定义房**：场上没有存活首都、且在座人数 ≥ 3 时可邀请组队（服务器不检查阶段，匹配房在定都前也能改队）。接受邀请即加入邀请方的队伍，并作废你收到的其他邀请；邀请不会过期。队伍人数没有上限，全房间可以是一队。任意首都放置后队伍冻结。
- 一旦出现过 2 人及以上的队伍，本局就进入组队模式，即使队伍后来解散也不退出。
- **组队模式首都**：沦陷后一律旁观，不可重新选都（覆盖房间重生开关）。
- **友军**：
  - 进攻命令不能以友军为目标；友军单位互不占格、不会自动交战；
  - 友方单位可穿过己方封锁且不受封锁伤害；
  - 友方建筑 / 单位信息板等同己方（只读，不能代操作）；
  - 通信视友方为己方（含友军电台扩大活动范围），直接视野共享；
  - 友军公路 / 铁路**不**给己方单位加速；友军视野与路网**不**算作己方建造许可；
  - **不能**使用友方补给站补给；**不能**与友方建筑互防；**不能**驻守友方建筑。
- **友方进驻**：野外单位可向友方建筑申请进驻；须建筑所有者批准后才并入该建筑在营 U，之后仅所有者可从该建筑派出。
  - 申请没有过期时间、距离限制和数量限制；同一单位可以向多座建筑申请，只拒绝完全重复的申请。
  - 批准时要求：建筑已建成（或是首都）且有空位、兵种匹配、单位不在训练送达或撤退中。批准后该单位从地图上移除，U 直接并入建筑（不论相距多远）。
  - 批准时不检查建筑通信、污染，也不检查单位是否在移动、交战、封锁或驻守。
- 聊天是全房间公开的，没有队伍频道。

### 5.2 掉线、离开与重连

- **掉线**：座位一直保留到房间关闭。经济、命令照常运行，没有托管 AI。用同一身份重连后一切恢复。
- 身份为客户端生成的标识，掉线 **7 天**后过期；昵称最长 **24** 字。
- **主动离开房间**：
  - 你的建筑、联络线、单位留在地图上，但不再结算你的经济（也就不会因 E 为负扣首都血）；
  - 你的队伍关系被删除；
  - 进行中的研究被取消，阶段不前进，已扣费不退。
- **离开后再进入**：研究进度恢复，但 E / O 重置为 500 / 10。读档局开始后，离开的玩家不能再进入。
- 场上没有任何玩家处于对局中时，模拟停止。

### 5.3 存档与读档

- **保存内容**：地图、种子、人数上限、重生开关、组队模式与队伍；全部建筑（含建造、修复、冷却计时）、联络线、单位及其命令、污染区、资源枯竭；通信状态、首都归属、观战者；每名在座玩家的 E / O、研究进度与进行中的研究；当前 tick（所有计时保持一致）。
- **不保存**：未处理的友方进驻申请、组队邀请、聊天记录、已离开玩家的 E / O。
- 任何在座玩家（含观战者）都可以导出存档；存档加密保存。
- **读档身份对应**：读档者继承存档者的身份；其他人按身份标识匹配，或手动选择继承；若只剩一名玩家和一个未认领的存档身份，自动配对。
- **读档局大厅**：读档者无需定都；对局开始前允许新玩家入座；无人认领的身份作为无主势力留在地图上，保留队伍，其首都仍算存活。读档局同样需要所有人按下准备后才开始。

**火箭军研究解锁**

导弹 / 远程导弹 / 核导弹在建造前须完成本局研究解锁（与建筑 `prereq` 链独立：未研究不能建造/升级到该级；研究依赖另计）。每位玩家本局独立进度；存档继承身份时一并恢复；重生、离开后再进入都保留已解锁项与当前阶。

- **发起**：在建造树点击锁定条目 → 确认投入本阶研究；服务器扣本阶 E/O，开始**计时研究**（耗时 = 本阶能源 / 50 秒），同时仅可进行一项研究。研究不要求接入通信，也不要求拥有臼炮等建筑（核导弹研究的设施要求见下）。
- **结算**：计时结束时掷骰；成功则该项永久解锁（本局）；失败则进入下一阶（已扣费不退）。已解锁后忽略再研究。

- **核导弹研究设施**：发起时、进行中每 **5 秒**（按房间全局时钟）、以及计时结算前，均须同时拥有已接入通信、已建成、未污染、且脚下铀矿未枯竭的铀矿机，以及已接入通信且正在工作的铀工厂（与核装填前置相同）；门槛失效则中止当次研究（不进入下一阶，同阶可重试；已扣费不退）。普通掷骰失败仍进入下一阶（已在末阶则保持末阶可重试）。

**母舰**

- 在已接入通信、未污染的港口建造：消耗港口 **1U** 海军作为船体，**2000E**。移速 0.4 Du/s，不能改归属。单艘母舰的当前舰体 HP 可累积受损，满值为 **10HP**；降至 **0HP** 才被击沉，不按每 U 静态倍率折算。
- 检视 HUD：先显示舰体 HP，再显示「舰载机编制」；选中时绘制 **R = 8 Du** 蓝色出击/部署范围圆（与建筑工作范围同色描边）。
- 机库最多 **5U** 空军。同格且有空位时，停留中的空军自动装入。「部署」按钮样式与「撤退」相同：打开机场驻军选择（不含已派出的野外空军），至多 **5U**，确认消耗 **5 O**；空军飞向母舰，途中经过敌方防空炮工作范围（含雷达协同）时按既有对空交战规则结算；抵达后删除该空军单位并并入载机编制。
- 母舰撤退时返回所属港口旁最近的可站立海格，状态变为**停港**，继续留在场上、不入库。停港期间每 **2 秒**恢复 **1** 点舰体 HP。
- 舰载机出击打击范围为以母舰当前位置为圆心、**R = 8 Du**；母舰移动时范围随之移动。舰载机或攻击目标超出范围时，中止攻击并返航；打击后也返航。返航后自动上舰。母舰被击毁时，仍在飞行中的舰载机改返各自原所属机场。普通机场空袭规则不变。

**发射冷却**

冷却秒数 = 装填单发 E / 30，向上取整到 0.2 秒：臼炮 2.8，防空炮 3.4，导弹 6.8，远程导弹 20，核导弹 166.8。防空炮拦截导弹、开始对空交战也会触发自己的冷却；冷却中的防空炮既不拦截、也不开始新的对空交战。

**核导弹与污染**

- **装填**：须同时拥有已接入通信、已建成、未污染、且脚下铀矿未枯竭的铀矿机，以及已接入通信且正在工作的铀工厂，否则拒绝装填。
- **命中**：对目标造成无限伤害并摧毁；在命中点生成持久**污染区**（半径 **R = 2 Du**）。被防空炮拦截则没有伤害，也没有污染。多次命中产生的污染圆各自独立、可以重叠。
- **污染区内**：禁止新建建筑；区内已有建筑**失效**（通信、生产、训练、雷达、防空、发射等停用），**仅可拆除**；工地暂停施工。污染不伤害单位。
- **首都**若落在污染范围内：每 **3 秒**扣除 **1** 点 HP（会打断首都修复）。污染中的首都不再向外扩散通信。

**防空炮结算**

- **拦截导弹**：火箭军弹道（导弹、远程导弹、核导弹；**不包括臼炮**）经过的整条发射线上，与发射线最近、且线段进入其工作范围（含雷达协同）的敌方防空炮负责拦截——即使目标本身不在它的范围内。每次拦截消耗 **1 枚**弹药；弹药用尽或冷却中则不拦截。拦截瞬间完成。
- **对空军**：敌方空军进入防空炮工作范围后，若该炮弹药 ≥ 2 且不在冷却中，消耗 **2 枚**并开始减员。此后每秒累计「进入前 U × 10%」的减员，满 1 才扣 1U（例如 4U 每 2.5 秒掉 1U），直到剩余 U 降至 **⌊进入前 U × 50%⌋**。因此 1U 的空军会被全歼，3U 降到 1U。
- 同一组空军同时只被一座防空炮交战，多座防空炮不叠加。离开范围后这次交战结束；重新进入或进入另一座防空炮的范围会重新开始（再耗 2 枚，重新计算 50% 下限）。
- 防空炮工作不要求接入通信（但雷达协同要求接入）。

## 8. 界面交互

### 8.1 基础界面显示

- 地图底色为暗灰（网格线为稍浅的灰），其上按地形着色：海洋深蓝灰、陆地暗绿灰、山地灰褐、林地绿色；油田、铀矿只画格子描边（金黄、黄绿）。可选 **89×59** / **119×79** / **179×119**（90×60 / 120×80 / 180×120 条网格线）。建筑建在格点上。
- 左上角圆环表示首都血量，直径取「窗口横纵像素里较长一边的 **1/16**」与右侧能源 / 组织点区块高度中较小的一个，绕满一圈为当前 HP 上限（首都建筑为 120）。
- 圆环右侧为能源和组织点。图标为 `/ui/energy.png`、`/ui/organization_point.png`。上排能源，下排组织点；组织点下方是组织点槽，**50** 为满。
- 右下为小地图（面积约为窗口的 1/30，按地图比例），只在对局中显示：显示地形与当前视口框，不显示单位和建筑；己方建筑被毁（自己拆除的除外）时，在该处显示 **12 秒**警告图标。聊天贴在小地图上方。
- 聊天发给全房间所有人（含敌方与观战者），每条最多 **200** 字，连续空白会被合并；记录只保存在本地。
- 可线性升级的建筑，己方看到图标左下角的罗马数字等级（白字）；友军建筑不显示。
- 发射冷却中的建筑，图标上覆盖灰色扇面，表示剩余冷却比例。
- 未接入通信的己方建筑以 **45%** 不透明度绘制；施工暂停的工地再叠加一层变淡（55%）。
- 选中建筑或单位进入检视时，地图变暗，只保留被选中的图标。一条线从信息面板连到目标。

  - **通信状态**：已接入的图标染青色，未接入的染红色，并画出电台范围与正在传递信号的联络线；
  - **敌方视野**：画出可见敌方实体的视野圆并集（只是估计，见附录）。

### 8.2 游戏操作

- 点空地或坐标：半环菜单为**调动、封锁、建造**。选都阶段只有**定为首都**。
- 放大到足够近、点击范围内同时有坐标 / 建筑 / 单位时，先弹出环形点选，再进入对应检视或坐标菜单。
- 己方建筑信息面板：红条 HP，黄条 U（外出占用为深黄），绿条补给站储能，蓝条弹药。可显示等级、储量、通信与训练队列。
- 地图上建筑图标下方：HP 条之下最多再显示一条，优先级为储能（绿）> 弹药（蓝）> U（黄 / 深黄）。因此补给站在地图上不显示 U 条。
- 敌方建筑：卫星下只有类型；直接视野下有类型和 HP。敌方单位只显示兵种和状态，不显示 U。
- 建筑上常见操作：升级、线性升级、修复、继续建造、拆除、装填、部署、训练、建造航母、驻守、补给、互防 / 解除互防、发射、进攻、迁都。
- 单位上常见操作：调动、封锁、驻守、进攻、补给、停止、撤退；母舰可「部署」机场空军上舰。
- 建造菜单只在格点周围 4 格全是海洋时按「海上」处理（可建人工岛、不可建普通建筑），否则按陆地处理。
- 除拆除外，未接入通信的建筑在界面上不能操作（修复按钮也被禁用，即使服务器允许修复刚占领的建筑）。污染建筑只保留拆除。

## 9. 附录 · 已知实现问题

以下是当前代码中与本文规则意图不一致、或明显异常的行为。规则以正文为准，这里供玩家知悉。

- **地面占领敌方首都**：首都被地面攻城打到 0 时会走「占领」流程，结果占领方与原主人**都**被判首都陷落而出局。
- **友军保护不完整**：发射（含核导弹）可以打友军建筑和单位；进攻可以拆友军联络线；防空炮会击落友军空军、拦截友军导弹。
- **队友离开房间**后变成敌方，其首都仍存活，会阻止本队获胜。
- **总司令部**唯一性未强制，可以建多座。
- **建造地形**由客户端上报，服务器不复核（理论上可在陆地建人工岛、在海上建陆地建筑）。
- **视野外的升级**：建筑在升级中不提供视野，若它是该格唯一的视野来源，升级会永远暂停（HP 0）；此时拆除按「尚未开始」返还 100%。
- **视野外的工地仍接入通信**并重置信号预算，可用连串暂停的工地把通信延伸进迷雾。
- **施工中的电台、雷达**已参与通信跳转与雷达协同。
- **施工判定不算友军视野**，但客户端显示的「施工暂停」算了友军视野，两边可能不一致。
- **撤退锁死**：撤退中的陆军被进攻方钉住后，战斗结束会停在原地并保持「撤退中」状态，之后不接受任何命令。
- **一个目标被多组同时进攻时**，交战轮次会快于每 5 秒一轮。
- **驻守状态残留**：驻守单位被拖入交战或做了极短移动后仍保留驻守标记（免费守卫、阻止互防）；所驻守的建筑消失后仍继续扣维持费。
- **占领后的旧单位**：原主人的外出单位仍指向被占领的建筑，它们阵亡时会扣减新主人的外出占用。
- **占领绕过研究**：占领敌方导弹类建筑后，即使 HP 0 待处理、自己未研究，接入通信也能装填和发射。
- **训练送达中的单位**可被停止或改道，会打乱目标建筑的空位计数。
- **发射摧毁建筑**时不会解除它的互防关系，伙伴可能残留互防标记。
- **完工补满驻军**不计外出占用，升级完成后在营 + 外出可能超过 Umax。
- **离开再进入**会把 E / O 重置为 500 / 10，可用来刷低能源，也可能白白损失高能源。
- **出局 / 观战玩家**拥有全图视野（含敌方 U）且能使用全房间聊天。
- **读档大厅**会显示所有建筑和线缆（超出卫星视野应有的范围）；在读档大厅放弃首都会永久删除存档中的首都。
- **矿点**：新矿块可能覆盖旧矿块的格子；2 格的小油田储量可能为 0；部分 2×2 矿块的储量环位置偏移半格。
- **友方进驻申请**在建筑易主后仍会显示给新主人（含兵种与 U），单位或建筑消失后申请也不会自动清除。
- **空闲超时**只看玩家操作，大家都在观望的慢节奏对局也会在 5 分钟后被关闭。
